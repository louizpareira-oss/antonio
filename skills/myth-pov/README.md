# Myth POV skill folder

Save this whole folder (`skills/myth-pov/`). To use it as a Claude Code skill, put it in `.claude/skills/myth-pov/`
of the repo (or `~/.claude/skills/myth-pov/`); Claude loads `SKILL.md` automatically when the task fits.

- `SKILL.md` — the master system (start here)
- `references/` — channel identity, formula, style bible, shot library, script formula, workflow, upload, flip & fix,
  7 frame-by-frame reference breakdowns, CMU mocap index
- `scripts/` — install.sh, fetch_mocap.sh, build_character.py (Blender), new_project.sh, measure_reference.py
- `studio/` — myth3d.js (engine kit) + project template (2 working shots)
- `examples/first-test-render.png` — first render of the template (mocap hero, day + candle presets)
The reference videos themselves are not included (they belong to their creators).
