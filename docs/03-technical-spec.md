# 3. Technical spec

Print this. Check every video against it before posting.

## Export settings (CapCut)

| Setting | Value | Why |
|---|---|---|
| Resolution | **1080×1920** | Below this reads as low quality. Your current 768×576 is roughly a quarter of the required pixels. |
| Aspect ratio | **9:16, full bleed** | No black bars, no framed box, no letterbox. |
| Frame rate | 30 or 60 fps | 60 if the source footage supports it. |
| Bitrate | Highest available | CapCut: "Recommended" or higher. |
| Length | **65–90 seconds** | Creator Rewards pays only on videos over 60s. Never export at 55–62s — leave margin. |
| Codec | H.264 | Default. |
| Watermark | **Off** | Turn off the CapCut end-card and watermark in CapCut settings. |

## Auto-fail checklist

Any one of these can sink a video, and repeated offenses sink the account:

- [ ] Black bars or empty space anywhere on the frame
- [ ] Another platform's watermark visible (Pinterest, Instagram, YouTube, Giphy, CapCut)
- [ ] A logo or username from another creator in a corner of a downloaded clip
- [ ] Screen recording of anything
- [ ] Slideshow of still images with no motion
- [ ] Split screen with someone else's video
- [ ] Identical opening frame on every post (template look)
- [ ] Under 60 seconds, if you want it to earn
- [ ] AI visuals without the AI-generated label enabled

## Caption safe zone

TikTok's UI covers real estate. Keep all text inside:

- **Top:** 12% clear (search bar, "Following/For You")
- **Bottom:** 20% clear (caption, sound, nav bar)
- **Right:** 20% clear (like/comment/share column)

Text outside that gets covered, which looks careless to both viewers and reviewers.

## Upload settings

- Upload the **highest quality** version — in TikTok's upload screen turn on
  "Upload HD" / "Allow high-quality uploads" (Settings → Content preferences).
- Post from the phone that filmed it when using Route A. Native metadata helps.
- Write a real caption. Not just hashtags. One line that adds to the video.
- 3–5 relevant hashtags. Not 30. Not #fyp #viral #foryoupage stacked.
- Do **not** post the same video to TikTok and Instagram with the other app's watermark on it.
