# Thumbnail — What If You Got 2x Heavier Every Single Day?

Made by the user in SeaArt/Midjourney from this prompt (rules: CLAUDE.md and `docs/13-thumbnail-patterns.md`).
Formula from the winners: calm hero, one giant consequence touching him, "TOO ___." text in the empty corner.

angry/evil instead of calm-smug, the frame was cluttered (bridge, skyline, taxi, water, beams) with no empty corner for
the text, the taxi wasn't crushed by him, and SeaArt invented lettering on the taxi.
